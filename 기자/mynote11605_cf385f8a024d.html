텔레그램 + 티스토리

Helena Workflow · Process Standard v1.0

Paste Pipeline: 터미널에서 티스토리까지

Claude Code → GitHub Actions → Telegram → (사람 복붙 5클릭) → Tistory HTML 발행

한 줄 요약

Claude Code로 만든 HTML 페이지를, Telegram 첨부파일 하나로 받아서, 티스토리 HTML 모드에 5번 클릭으로 붙여넣는다.
티스토리는 API가 없다. GUI 자동화는 가성비가 안 나온다. 그래서 이 파이프라인이 유일한 실용적 솔루션이다.

️ 전체 워크플로우

왜 이렇게 해야 하나 — 티스토리 자동화의 현실

시도했지만 안 되는 것들

❌ 티스토리 API

티스토리 Open API는 읽기 전용이다. 글 목록·카테고리·댓글 조회만 가능. 글 발행 API는 존재하지 않는다.

❌ Selenium / Puppeteer GUI 자동화

로그인 세션 관리, CAPTCHA, UI 변경 추적, 유지보수 비용이 사람이 5번 클릭하는 것보다 훨씬 크다. 가성비 0.

❌ 티스토리 마크다운 모드 직접

마크다운은 인터랙티브 요소(아코디언·SVG·CSS 애니메이션)를 표현할 수 없다. 정보 전달력이 HTML 모드의 30%.

❌ GitHub Pages 직접 사용

GitHub Pages만으로는 한국 블로그 생태계(티스토리) 유입을 못 받는다. 검색 노출·댓글·방문자 통계가 티스토리에 집중.

그래서 Paste Pipeline

비교API 자동화GUI 자동화Paste Pipeline
가능성불가능가능하나 비쌈✅ 작동 중
유지보수—UI 바뀔 때마다 수정없음
사람 개입0거의 05클릭 (30초)
HTML 모드—가능✅
월 비용—서버 + 유지보수$0
결론: 티스토리에 HTML 인터랙티브 페이지를 올리는 방법은 사람이 HTML 모드에 붙여넣는 것뿐이다. 그 "붙여넣기"까지의 모든 과정(코딩·변환·전달)을 자동화하고, 마지막 5클릭만 사람이 하는 것. 이게 Paste Pipeline이다.

터미널에서 무슨 일이 일어나나

STEP 1

Boss가 Claude Code에 프롬프트 입력

S21 proot Ubuntu 터미널에서 claude 실행. "ParksyCapture 백서 HTML로 만들어서 텔레그램으로 보내" 같은 지시. DeepSeek 모델로 구동.

STEP 2

Claude Code가 HTML 파일 생성

Write 도구로 templates/*.html 작성. JS-free, CSS-only, Tistory HTML 모드 호환 확인. 다크모드 대응 포함.

STEP 3

git commit + push

helena-programming 레포에 커밋 → GitHub로 푸시. 커밋 메시지에 "왜" 포함.

STEP 4

GitHub Actions 자동 트리거

push 감지 → log_to_telegram.sh --html 실행 → parksy_to_html.py 변환 (또는 기존 .html 그대로) → Telegram sendDocument API 호출.

STEP 5

@helena_logbot 메시지 도착

Boss의 Telegram (아무 기기)에 .html 첨부파일 + 설명 메시지 도착. 알림으로 확인 가능.

터미널 세션 = 1회성. Claude Code가 생성한 HTML은 GitHub에 영구 저장된다. 같은 페이지를 다시 만들 필요 없이, git log에서 언제든 복원 가능.

️ 5클릭으로 티스토리 발행하기

Telegram에서 .html 파일을 받은 후, 웹 브라우저에서 티스토리까지 5번 클릭이면 끝난다:

왜 티스토리인가 — 멀티채널 전략

같은 콘텐츠가 여러 채널에서 다른 역할로 존재한다:

채널형식역할발행 방법
GitHub.md 원본영구 저장·버전 관리·검색자동 (git push)
TistoryHTML 인터랙티브한국 검색 노출·블로그 유입Paste Pipeline (5클릭)
GitHub PagesHTML 정적 호스팅글로벌 접근·빠른 로딩자동 (GitHub Actions)
YouTube숏폼 영상영상 검색·구독자 유입PD Pipeline (P0~P6)
Naver웹진·미끼네이버 검색·카페 유입Paste Pipeline (수동)
티스토리는 한국 블로그 SEO의 중심. 네이버·다음 검색에 가장 잘 노출되는 플랫폼 중 하나. API가 없어도 이 채널을 포기할 수 없는 이유.

✨ 정리 — Paste Pipeline의 철학

자동화할 수 있는 99%는 자동화한다. Claude Code가 코드를 쓰고, GitHub Actions가 변환하고, Telegram이 배달한다.

자동화할 수 없는 1%는 사람이 한다. 티스토리 HTML 모드에 붙여넣는 5번의 클릭. 이 1%가 없으면 콘텐츠는 GitHub에만 머물고, 아무도 못 본다.

Paste Pipeline = 완전 자동화가 불가능한 플랫폼에서, 가능한 모든 것을 자동화하고 마지막 인간 터치만 남긴 설계.

터미널에서 명령어 한 줄 → 30초 후 티스토리 첫 페이지.
그 사이엔 Claude Code, GitHub Actions, Telegram, 그리고 Boss의 5클릭이 있다.
