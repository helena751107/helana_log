안드로이드 공유·봇·임시 메모 등 **비정제 원본**이 쌓이는 곳이다.

- 행정 대화록으로 쓸 가치가 있으면 → `docs/dialogue/` 템플릿으로 **정제 이전**  
- 개인정보·토큰이 있으면 → 올리기 전 삭제·재발급  
- 더 이상 일반 코딩 일지 전용 공간이 아니다. 기술 트러블슈팅은 다른 레포를 우선한다.

## 에이전트 마크 (개발·세션 로그)

기술/세션 로그 파일명은 접미 마크를 쓴다 (수첩 규약과 동일):

| 마크 | 작성 주체 |
|------|-----------|
| `_Grok` | Grok Build / SuperGrok |
| `_Claude` | Claude Code (`cc`) |
| `_Aider` | Aider (`ds`) |

예: `DevLog_20260726_Grok.md`
