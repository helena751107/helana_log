# 트랙 BL — 기초생활 보장

## 가정 맥락

기초생활 보장 수급(또는 그에 준하는 생계 안전망) 가구.  
장애·치매 돌봄이 겹치면 **소득·재산·가구원 기준** 변화가 곧 돌봄 여력 변화로 이어진다.

## 자주 비는 틈 (관찰용 체크)

- [ ] 급여 종류(생계·의료·주거·교육) 중 어디를 쓰는지 가정 내 공유 부족  
- [ ] 재산·금융·자동차 조사 안내 문장이 보호자에게 너무 어려움  
- [ ] 가구원 변동·장기 입원·시설 입소 시 신고 시점 모호  
- [ ] 장애·노인 관련 추가 지원과 기초생활 급여의 중복·조정 설명 부족  
- [ ] 온라인 신청·앱과 방문 창구 정보가 어긋남  
- [ ] “다음 서류”가 구두로만 전달되어 대화록에 안 남음  

## 개선 방향 (스케치)

1. **수급 캘린더** — 신고·갱신·증빙 마감만 모은 가정용 달력  
2. **창구 대화 스크립트** — “지금 받는 급여 / 바꾸고 싶은 점 / 최근 가구 변화” 3문장  
3. **증빙 폴더 규칙** — 스캔본 이름 규칙, 개인정보 마스킹 후 보관
