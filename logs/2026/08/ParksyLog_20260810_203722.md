맞다, 여러 번 얘기했다. 프로 쓴다는 거 안다. 내가 그 얘기 방금 놓친 거다.

프로만 쓰는 거면 SONNET/HAIKU 자리 신경 쓸 필요 없다 — 어차피 안 쓰는 자리다. cc한테 이렇게만 시켜라:

난 SONNET이나 HAIKU 안 쓰고 계속 PRO만 쓴다. 
그 두 줄(ANTHROPIC_DEFAULT_SONNET_MODEL, ANTHROPIC_DEFAULT_HAIKU_MODEL) 
신경 쓸 필요 없으니까 settings.json에서 그냥 지워. 
ANTHROPIC_DEFAULT_OPUS_MODEL: deepseek-v4-pro 이거 하나만 남기고 나머진 정리해.
이러면 안 쓰는 모델 이름 갖고 앞으로 또 이런 소동 안 난다.

PHASE 1 — 토큰 이슈 리포트
증상: DeepSeek 잔액이 빠르게 소진됨(402 Insufficient Balance), 최소 두 번(누나 폰, 그리고 오늘 재확인 세션) 발생.

근본 원인 (확정): Claude Code가 매 요청마다 <claude_code_attribution> 블록에 랜덤 UUID+타임스탬프를 삽입 → DeepSeek 캐시는 프리픽스가 0바이트부터 완전 일치해야 히트되는데, 매번 다른 랜덤값이 앞에 붙어 캐시가 100% 미스됨 → 캐시미스는 히트 가격의 약 50배(공식 확인). 여기에 죽은 모델명(deepseek-chat, 7/24 폐기)을 SONNET/HAIKU 자리에 두 번 반복해서 넣은 부수적 실수도 겹쳤었다.

최종 해결책 (검증 완료):

json
{
  "env": {
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "ENABLE_TOOL_SEARCH": "true",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro"
  }
}
~/.claude.json에 hasCompletedOnboarding: true + primaryApiKey 패치(서드파티 엔드포인트 쓰면 로그인 벽 뜨는 부작용 방지).
PHASE 3 — 다른 폰들(호야당 아저씨, 친구, 누나 폰)에 그대로 배포
각 폰 root@ 상태에서 이거 한 번 실행하면 오늘 고친 것 그대로 적용된다:

bash
mkdir -p ~/.claude
cat > ~/.claude/settings.json << 'EOF'
{
  "env": {
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "ENABLE_TOOL_SEARCH": "true",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro"
  }
}
EOF

python3 -c "
import json, os
p = os.path.expanduser('~/.claude.json')
try:
    with open(p) as f: d = json.load(f)
except FileNotFoundError:
    d = {}
d['hasCompletedOnboarding'] = True
d['primaryApiKey'] = os.environ.get('DEEPSEEK_API_KEY','')
with open(p,'w') as f: json.dump(d, f, indent=2)
print('patched:', p)
"

exit
~ $로 나온 뒤 cc 다시 켜면 적용된다. 세 폰 다 이 한 덩어리만 붙여넣으면 끝이다.
