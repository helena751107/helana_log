# 헬레나가 사는 법 — How Helena Lives

> **조현병과 함께 사는 누나를 위해, 돌봄을 기술로 번역한 기록.**
> 하루를 살아내는 누나의 방식을 Scene(장면) · Feel(느낀 것) · Way(살아낸 법) · Next(다음 하루)로 남긴다.
> 그리고 그 곁에, 24시간 깨어 있는 **수호천사(돌봄 데몬)**를 세워둔다.

## 이 레포가 뭔가요?

누나의 인생 스토리를 기록하는 곳이에요. 진료 원문도, 행정 민원도 아니에요.
신앙·음악·가족의 돌봄 속에서 **누나가 오늘 하루를 어떻게 살아냈는지**를 정직하게 남겨요.

두 갈래로 나뉘어요:

| 갈래 | 폴더 | 내용 |
|------|------|------|
| **인생 스토리** | `docs/tracks/` · `docs/dialogue/` | 삶의 장(章)과 하루의 기록 (Scene/Feel/Way/Next) |
| **돌봄 데몬(수호천사)** | `docs/care-daemon/` | 배터리·체온·위치·원격 돌봄을 지키는 기술 |
