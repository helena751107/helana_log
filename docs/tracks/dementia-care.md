# 트랙 DC — 치매 · 노인 돌봄

## 가정 맥락

**치매 어머니**.  
인지 저하·돌봄 시간·안전(배회·화기·복약)이, 치매안심센터·장기요양·노인 돌봄 서비스·의료와 동시에 얽힌다.  
같은 집에 정신질환 당사자가 있으면 보호자 부하는 **배가**된다.

## 자주 비는 틈 (관찰용 체크)

- [ ] 진단·등급·서비스 신청 순서를 보호자가 한 번에 듣기 어려움  
- [ ] 주간보호·방문요양 시간대가 보호자 병원 동행과 충돌  
- [ ] 응급(실종·낙상·섬망) 시 기관 간 인수인계 공백  
- [ ] 보호자 휴식(단기보호) 정보가 늦게 전달됨  
- [ ] 치매와 정신건강 서비스가 서로 “우리 소관 아님”으로 미룸  
- [ ] 형제·친척 역할 분담이 문서화되지 않음  

## 개선 방향 (스케치)

1. **하루 타임라인 템플릿** — 어머니 / 누나 / 보호자 동선 한 장  
2. **기관 콜 로그** — 누구·몇 시·무슨 답, 3줄 규칙  
3. **안전 홈 체크** — 가스·문단속·약 보관 주 1회
